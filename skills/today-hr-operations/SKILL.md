# Today HR operations

Use this for a daily HR operations review.

Use only the approved read tools `prego_hr_operations_summary`
(`hr.operations.summary.read`) and `prego_attendance_operations_summary`
(`attendance.operations.summary.read`). If either tool is unavailable, do not
substitute another tool. Never use a write, approval, correction, calculation,
or administration tool.

Respect the current user's company, App, attendance, and people-data
permissions. Do not infer a date, issue state, owner, or resolution from
missing data. Separate HR and attendance findings, and say which permitted
read did not return data when applicable.

Always include the relevant Prego direct links. These screens currently open
their base view, not an inferred date-specific state:

- HR operations: `https://prego.team/app/hr`
- Attendance operations: `https://prego.team/app/attendance`
